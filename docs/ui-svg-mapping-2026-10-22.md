사용자 확인 사항:

- 알림 설정·환경설정은 표시만 한다. 새로운 설정 저장이나 권한 요청은 없다.
- 키워드 미션은 해당 태그를 포함한 본인 공개 코스 저장을 확인한다. 미션당 300P를 1회만 지급한다. 비공개·가상 사용자·기획코스는 제외한다.
- 미션과 포인트는 기존 회원별 브라우저 시연 저장 구조를 재사용한다. 실제 쿠폰 지급·외부 이벤트 신청이나 서버 포인트 제도를 추가하지 않는다.
- 기존 공개/나만의 코스 관리는 마이 > 내 코스에서 유지한다. 기존 여행기 작성/해제는 카드 관리 메뉴에서 유지한다.

자산: 업로드 SVG에서 리워드 아이콘·체험단·미션 사진을 추출해 `public/images/design-20261022/`의 WebP로 최적화했다. SVG 원본 전체를 배포 자산으로 복사하지 않는다. 글자는 기존 시스템 글꼴로 구현하므로 윤곽선으로 저장된 SVG 글자와 자형 차이가 있을 수 있다.

검증: Vite 빌드, React 정적 화면 렌더링, 공개 여부·태그·미션 중복 적립 검사를 수행했다. 실제 회원 생성·코스 저장·포인트 적립·DB 변경은 실행하지 않았다.
