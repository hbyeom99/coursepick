# 페이지 로딩

화면 중앙 보라색 회전 아이콘과 `페이지를 불러오고 있어요` 문구를 사용한다. 초기 앱 모듈, 홈 코스 조회, 검색 코스 계산, 편집 장소 조회, 여행기·마이 지연 모듈에 적용한다.

화면 전환 후 화면에 보이는 이미지의 준비 상태를 확인한다. 공통 이미지 컴포넌트의 사전 로딩 및 카카오 상세 사진 URL 조회도 확인하며, 화면 밖 이미지까지 모두 기다리지는 않는다. 200ms 동안 준비 상태가 유지되면 표시한다. 자동 배너 사진 전환으로 완료한 로딩 화면을 다시 띄우지 않는다.

각 화면 로딩 세션은 최대 30초다. 상한 이후에는 화면을 열고 기존 오류·대체 이미지 처리를 사용한다. 이미지 지연은 추가 네트워크 호출 없이 기존 조회 상태로 판단한다. 홈 코스 요청도 30초에 중단하고 재시도 안내를 제공한다. 모션 감소 설정에서는 회전하지 않는다.

확인: Vite 빌드 성공(기존 청크 크기 경고), 실제 로컬 홈 로딩 해제 및 콘솔 오류 없음. 테스트 화면에서 데이터가 계속 대기 중이어도 30초 후 로딩 화면이 해제되는 것을 확인했다. 최종 홈 요청 타임아웃·모달 키 보완은 로컬 Vite 변환으로 확인하며 빌드를 반복하지 않았다.
