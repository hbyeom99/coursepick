# Coursepick 프론트·백엔드 워크플로우

현재 로컬 소스 기준으로 작성한 흐름도입니다. 운영 배포 상태를 확인한 자료는 아닙니다.

- 프론트엔드: React/Vite. 홈 키워드 해석과 성향·동선·다양성 기반 추천 코스 조합은 `src/lib/homeKeywordCourses.js` 등에서 실행합니다. 외부 LLM 호출을 의미하지 않습니다.
- 백엔드: Python/FastAPI. 회원 인증, 장소·코스 조회, 외부 검색·경로 조회 대행, 개인 데이터와 Zip 저장을 담당합니다.
- Supabase: Auth, Storage, 장소·코스·회원 데이터 및 Zip 방·멤버·초대 자료.
- Kakao Maps JavaScript API: 프론트엔드 지도 표시. Kakao Local 및 모빌리티 키는 백엔드에서 사용합니다.
- TAGO: 대중교통 보조 조회. 실제 경로·지원 범위와 추정 구간은 화면 구현에 따릅니다.
- TourAPI: 별도 수집·검토 작업 후 승인된 장소 DB에 반영합니다.
- Google 보조 조회는 별도 제공자 흐름이며 Kakao 지도와 콘텐츠를 합치지 않습니다.
- 실시간 검색 본문을 영구 저장하지 않으며, 허용된 장소 ID와 사용자 일정·조회 조건만 참조로 저장합니다.

흐름도의 화살표는 대표 연결입니다. 예를 들어 장소 검색 API는 장소 DB뿐 아니라 Kakao Local에도 요청하며, 브라우저 추천기는 반환된 후보를 이용합니다. 프론트엔드 추천 계산과 서버의 기존 추천·코스 생성 엔드포인트는 구분합니다.
