# 비회원 탐색·방 참여·개인 코스 일차 변경

2026-10-20. 로컬 코드만 수정했으며 배포·GitHub 푸시는 하지 않았습니다. 새 DB 테이블·환경변수 변경은 없습니다.

## 방 참여

여행코스.zip의 방 만들기 왼쪽에 방 참여하기 버튼을 추가했습니다.

1. 링크 주소 입력 팝업에서 공유받은 링크를 입력합니다.
2. 유효한 초대이면 비회원도 방 이름·대표 이미지·소개·인원만 미리 봅니다. 참여 전에는 최종 일정·멤버 성향 점수·회원 ID를 제공하지 않습니다.
3. 방 참여하기를 누르면 회원은 참여 후 멤버 성향 화면으로 이동합니다. 비회원은 로그인 또는 가입 후 같은 참여를 이어갑니다.
4. 나중에를 누르면 참여하지 않습니다.
5. 잘못된 주소·없는 방·만료된 초대는 ‘올바르지 않은 코드 또는 방이 없습니다’ 오류 화면에서 재입력할 수 있습니다.

## 비회원과 로그인

- 첫 진입은 홈입니다. 회원 세션이 있으면 복구한 후 홈을 엽니다. 비밀번호 복구 링크·명시적 Zip 링크는 해당 흐름을 유지합니다.
- 비회원도 검색·상세보기·코스 작성·일차 추가·내 코스/마이 화면 열람이 가능합니다.
- 코스 저장·좋아요·장소 저장·프로필 수정 등 회원 기능은 로그인하시겠습니까? 팝업에서 네/아니오를 선택합니다.
- 인증 화면 동안 편집 화면을 유지하므로 작성 상태를 잃지 않습니다. 회원가입 성공 후 로그인하여 같은 화면으로 돌아옵니다.
- 비회원 초안은 현재 탭의 sessionStorage에 보관합니다. 로그인 후에는 해당 계정에 분리해서 보관하며 다른 회원에게 보여주지 않습니다. 로그인 자체만으로 기존 회원의 서버 초안을 덮어쓰지 않습니다. 이어서 수정하거나 저장하면 기존 회원 저장 흐름으로 처리됩니다.
- 현재 탭을 닫거나 브라우저 저장 공간을 지우면 저장하지 않은 임시 초안은 없어질 수 있습니다. 비밀번호는 임시 초안에 저장하지 않습니다.

## 개인 코스 일차

- 개인 코스 편집·상세에 Zip 형태의 일차 탭을 추가했습니다. 편집의 + 버튼으로 최대 31일차까지 추가합니다.
- 선택한 일차에 장소를 추가하고 해당 일차의 장소·동선을 봅니다. 기존 schedule.day는 그대로 읽고, 새 일차 배정은 stopDays JSON과 durationDays로 저장합니다.
- 서버와 공개 목록에 새 필드를 반영하고 잘못된 일차 값을 검증합니다. 기존 코스를 일괄 수정하지 않았습니다. 날짜가 없는 코스에는 임의의 날짜를 넣지 않았습니다.
