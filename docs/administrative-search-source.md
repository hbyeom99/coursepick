# 전국 지역 검색어

- 자료: 행정안전부 행정표준코드관리시스템 법정동코드 전체자료의 공개 가공본.
- 배포 출처: https://github.com/wellsa-ai/admincode-kr (`kr/*.md`). 원본 출처: https://www.code.go.kr
- 가공본 생성일: 2026-10-01. 가져온 날짜: 2026-10-22.
- 시도·시군구·읍면동·법정리 명칭, 상위 지역을 붙인 표현, 시군구 접미어를 뺀 이름을 허용 목록에 추가했다.
- 같은 이름이 여러 지역에 있으면 어느 하나로 임의 확정하지 않는다. 주소의 행정구역 토큰으로 후보를 확인한다.
- 법정동 자료 기준이므로 행정동 전용 명칭·행정리·자연마을 별칭까지 모두 포함한다고 주장하지 않는다. 이후 행정구역 개편은 원본 갱신 후 다시 반영해야 한다.
- 지역 허용은 사용자 코스의 태그/제목 일치 규칙을 대체하지 않는다. 비공개 코스는 검색에 노출하지 않는다.
