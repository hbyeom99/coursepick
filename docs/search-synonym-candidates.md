# 검색 동의어 확장 후보 — 미적용

사용자 코스 검색은 현재 태그 정확 일치, 제목 문자 포함 순으로 후보를 구분하고 각 그룹에서 4축 성향 적합도순으로 정렬합니다. NFKC·공백·영문 대소문자·선행 #만 정규화합니다. 수제맥주는 맥주 태그의 정확 일치로 보지 않습니다. 제목에는 검색어가 문자 그대로 포함되어야 하며 동의어를 적용하지 않습니다. 기존 지역·기간·이동수단 등 필터는 유지합니다. AI 코스 생성과 장소 검색의 기존 확장 규칙은 별도입니다.

## 완전 동의어로 합치지 말아야 할 관련어

- 맥주 → 수제맥주·로컬맥주·IPA·사워에일 (하위 유형)
- 맥주 → 펍·브루어리·양조장·바틀샵 (장소 유형, 다른 주류도 취급)
- 카페 → 커피·디저트·브런치 (상품·활동, 범위 다름)
- 바다 → 해변·해수욕장·오션뷰 (장소·시설·조망 구분)
- 산책 → 걷기·둘레길·트레킹 (활동 강도와 대상 다름)
- 온천 → 스파·사우나 (시설·서비스 다름)
- 역사문화 → 박물관·사찰·문화유산 (상하위 주제)
- 무료주차 → 주차가능 (무료 여부는 별도 확인)
- 키즈존 → 유아 동반 (동반 가능 및 시설 근거 별도)

확장 도입 시 정확 태그 일치 그룹보다 뒤에 별도 그룹을 두고, 검색 결과에 확장 근거를 표시하는 방식을 권장합니다. 현재 이 목록은 검색 동작에 연결하지 않았습니다.


## 승인된 단방향 확장

- 맥주 → 수제맥주, 로컬맥주, IPA, 사워에일, 양조장, 펍, 바틀샵.
- 사용자 요청에 따라 양조장·펍·바틀샵도 이 검색 그룹에 포함한다. 실제 맥주 판매 여부를 확인했다는 의미는 아니다.
- 적용 순서: 코스 태그 정확 일치 → 등록된 하위 태그 정확 일치 → 제목에 검색어 포함. 각 그룹 내부는 사용자 성향 적합도순이다.
- 역방향·연쇄 확장과 다른 검색어의 확장은 적용하지 않는다. 포함 장소의 정보만으로 사용자 코스를 검색 결과에 추가하지 않는다.
- 위 이전의 정확 일치 전용 설명과 양조장·펍·바틀샵 제외 제안은 이 승인 범위에서 대체한다.
