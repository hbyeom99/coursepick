# 내 여행기·마이 로컬 변경 (2026-10-20)

## 동작
- 기존 하트 저장 목록을 그대로 ‘내 여행기’ 탭에 연결한다. 하트만 누른 코스는 방문 지역에 포함하지 않는다.
- 제목·방문일·방문 장소·본문을 작성한 개인 여행기를 기존 회원별 member_data에 저장한다. 새 테이블·RLS·Storage 정책은 추가하지 않았다.
- 하트를 해제해도 작성한 방문 기록을 자동 삭제하지 않는다. 목록 아래 ‘작성한 방문 기록’에서 수정·삭제할 수 있다.
- 지도는 방문 장소의 주소를 시도·시군구와 매칭한다. 미확인 주소는 임의로 지역에 배정하지 않는다. 시도 색 진하기는 방문한 하위 행정구역의 비율에 따라 달라진다.
- 기존 17개 시도 여행 분류와 호환되는 2025-12-31 경계 스냅샷을 사용한다. 행정구역 변경 이후 주소는 일부 매칭되지 않을 수 있다.
- 마이는 계획성·경험 취향·탐색 성향·지출 성향 4개 독립 점수를 입력·표시한다. 기존 5축 점수를 임의 환산하거나 전체 AI 추천 계산을 변경하지 않았다. Zip 방의 멤버별 입력과 합산 계산은 유지한다.
- 2026 리캡은 방문일이 2026년인 작성 기록만 집계한다. 사진·동행인·이동거리 데이터는 수집하지 않으므로 ‘기록 없음’으로 표시한다. 저장은 텍스트 파일이며 공유는 브라우저 공유 또는 요약 복사다.
- 리워드·쿠폰·이벤트·리뷰미션·당첨내역·포인트 내역은 시연 전용이다. 시작 포인트 3,250P, 미션당 300P 1회, 교환 시 차감·쿠폰 생성, 사용 시연을 제공한다. 실제 결제·발급·접수·추첨은 없다. 데이터는 이 브라우저에 회원별로 분리 저장한다.
- 모든 주요 화면과 Zip 상세에서도 하단 메뉴를 고정한다.

## 검증
- 로컬 빌드 통과. 큰 청크 안내는 남아 있으며, 지도는 여행기 화면에서 별도로 불러온다.
- Backend 전체 46개 실행: 45개 통과, 기존 1개 건너뜀.
- 지역 매칭·연도 집계·빈 기록·잔액 부족·미션 중복 방지 검증 통과.
- 모바일 브라우저: 여행기 탭·서울 25구·마이·리워드·이벤트·리캡·비회원 로그인 안내·하단 메뉴 확인. 콘솔 경고/오류 없음.
- 격리된 임시 화면에서 실제 DB에 쓰지 않고 여행기 저장 후 서울 2/25 반영, 1,000P 교환 후 2,250P 잔액·차감 내역·쿠폰함 연결 확인.
- 실제 회원의 여행기나 성향을 변경하지 않았다. 실제 회원 계정의 서버 저장부터 재로그인 복원까지는 이번 작업에서 수행하지 않았다.
- 운영 배포·GitHub 푸시는 하지 않았다.

원본 기획안 사진은 별도 파일이 제공되지 않아 기존 장소 사진과 준비 중 이미지를 사용했다. 레이아웃·보라색 테마를 참조해 구현했으며 사진·일부 아이콘은 기획안과 다르다.
