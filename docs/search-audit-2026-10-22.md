# 2026-10-22 검색 품질 점검

## 실행 범위와 제한

- 브라우저 사용이 Work 설정에서 비활성화되어 화면 클릭·키보드·콘솔 점검은 하지 못했다.
- 실제 로컬 API의 장소 목록을 앱의 toPlace 변환기로 정규화하고, 앱과 동일하게 초기 샘플 장소와 합쳐 검색 함수에 넣었다.
- 허용 키워드 658개의 허용 여부·후보 판정 및 코스 생성을 검사했다. 검색 조건은 전체 지역·기간·이동수단, 성향 미입력(중립) 기준이다. 개인 계정의 비공개 기록이나 로그인 상태는 재현하지 않았다.
- 공개 시연 코스 680개에 대해 658개 키워드의 태그/제목 매칭과 일치 그룹 순위를 검사했다. 공개 응답 title 필드를 앱 name으로 변환했다. 개인화 점수는 중립값으로 검사했으므로 회원별 순위 검증을 의미하지 않는다.
- Kakao 실제 조회는 위험 사례 8개(오로라·별 많은·맥주·효도 여행·무료주차·지역 축제·빈티지숍·스파)와 분류 확인 2회, 승인 변경 후 3개 검색 재검사에 한정했다. 합계 외부 요청 35회. 모든 658개 키워드에 Kakao 실시간 조회를 했다는 뜻은 아니다. 기존 호출 제한을 우회하지 않았다. Kakao 응답 본문·장소명·주소·좌표를 파일로 저장하지 않았다.

## 확인된 문제

1. 초기 가상 장소가 실제 추천 후보에 섞인다. src/data/places.ts는 가상 예시 좌표임을 명시하지만 App의 catalog는 이 자료와 실제 DB를 합친다. 효도 여행 생성에서 골목 티룸 등 시연 장소가 실제 DB 장소와 함께 사용됐다. 실제 추천 경로에서 샘플을 분리해야 한다. 아직 수정하지 않았다.
2. 장소명 부분 문자열에 과도하게 의존한다. 스파 검색에서 스파이더스 클라이밍센터, 공존테니스파크 양주점, 대성인터스파 골프장이 중심 장소가 될 수 있다. 업종이 DB에서 관광지로 넓게 분류되어 1차 필터를 통과하고 이름의 스파 글자가 일치한다. 아직 업종/활동별 핵심 근거 구조로 전면 수정하지 않았다.
3. 효도/부모님 여행에서 공원 이름이 포함된 농구장·배드민턴장이 포함됐다. 사용자 승인으로 체육·동물카페 제외 규칙을 추가하고 농구장 제외 회귀 검사를 통과했다. 원자료가 부족하면 동물카페 여부를 확정하지 못할 수 있다.
4. 은하수 검색에 태화강 십리대숲의 은하수 조명이 포함됐다. 사용자 판단으로 허용하고 조명 연출이며 실제 밤하늘 관측이 아니라는 코스 설명을 추가했다.
5. 빈티지숍 검색이 의류·잡화 분류를 여행 업종에서 일괄 제외했다. 사용자 승인으로 해당 쇼핑 검색에 한해 허용했다. 실제 Kakao 재검사에서 15개 중심 후보, 코스 3개를 생성했다.
6. 스파 검색에 온천이 포함되지 않아 과도하게 제외됐다. 사용자 승인으로 온천·사우나 하위 관계를 추가했다. 실제 Kakao 재검사에서 15개 중심 후보, 코스 1개를 생성했다. 부분 문자열 오류(2번)는 이 확장과 별개다.
7. 운영기간·가격·편의 근거 부족으로 결과가 없는 검색어가 있다. 무료주차·24시간·지역 축제·가성비 등의 무결과가 곧 오류는 아니다. eventStartDate/eventEndDate 및 확인 비용·조건 정보의 수집/전달이 부족하면 보수적으로 생성하지 않는다.

## 후속 수정: 가상 장소·스파 오인식 차단

사용자 요청으로 가상 장소(p숫자 ID 및 명시적 가상 표식)는 추천 후보·장소 추가·교체에서 제외하고, 남아 있는 개인 초안은 가상 장소를 제거해야 저장하도록 했다. 과거 저장 자료를 자동 삭제하지 않는다. 서버 맞춤 코스 생성에서도 p숫자 ID를 제외했다.

스파 검색은 상호명 부분 문자열을 근거로 사용하지 않는다. 스파·온천·사우나 명시 태그 또는 원문 시설 분류가 있어야 중심 후보로 인정한다. 스파이더스 클라이밍·테니스파크·골프시설은 코스의 주변 일정에서도 제외한다.

실제 DB 후보 재검사: 효도 여행 5개·카페 5개 코스에서 초기 시연 장소명 0건. 스파는 DB 근거 부족으로 0개 생성하며 잘못된 체육시설로 채우지 않았다. Kakao 실시간 재조회는 이번 후속 수정에서 실행하지 않았다. 통합 검사 통과. 푸시·배포하지 않았다.
