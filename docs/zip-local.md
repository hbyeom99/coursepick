# Zip 로컬 기능

2026-10-20 추가. 앱 배포는 실행하지 않았습니다.

- 하단 메뉴 Zip → 내 방/참여중인 방 → 멤버 성향/추천 코스/최종 일정.
- 방 생성 시 이름·소개·지역·기간·대표 이미지를 저장하고 여행코스.zip 목록으로 돌아갑니다.
- 방 내부 공유 아이콘에서 회원 이름 검색 후 초대, 7일 유효 초대 링크 팝업, 웹페이지 열기를 제공합니다. 실제 회원에게 검증용 초대 메시지를 보내지는 않았습니다.
- 링크 참여는 로그인 후 명시적으로 참여하기를 눌러야 합니다. 비회원과 미참여 회원은 방 데이터를 읽을 수 없습니다.
- 모든 멤버가 일정 제목·날짜 추가·장소 추가/제거/순서·방문 시간을 수정합니다. 서버 revision 충돌 시 최신 상태를 다시 읽습니다. 다른 멤버의 변경은 화면이 보일 때 15초 간격으로 갱신합니다.
- 각 멤버는 자신의 4축 점수(0~100)와 키워드를 입력합니다. 축별 총합과 입력 인원 기준 최대값을 따로 표시합니다. 4글자 코드는 축별 중간값으로 결정합니다. 기존 앱의 5축 성향은 변경하지 않았습니다.
- 공동 키워드는 모든 참여 멤버가 고른 키워드의 교집합입니다. 추천 코스는 같은 지역의 기존 코스를 공동 키워드 우선으로 정렬합니다. 새로운 4축 기반 추천 모델 자체는 아직 설계·적용하지 않았습니다.
- 방 삭제·정보 수정은 방장만, 여행기 작성은 준비 중 버튼입니다.

## DB

backend/zip_rooms.sql을 Supabase에 적용했습니다. zip_rooms, zip_room_members, zip_room_invites와 방 생성용 함수를 추가했습니다. 새 테이블은 RLS를 켜고 브라우저 직접 접근을 막았습니다. 기존 테이블과 기존 회원 코스는 변경하지 않았습니다. 서버 전용 기존 Supabase 키를 사용하며 새 키는 추가하지 않았습니다.

로컬 링크는 localhost이므로 다른 기기에서 접속할 수 없습니다. 여러 기기에서 공유하려면 추후 사용자 승인 후 프런트엔드와 API를 함께 배포해야 합니다.

## 확인

- 로컬 Vite 빌드 통과.
- 공유 권한·잘못된 성향·일정 충돌·초대 대상 검증 9개 모의 테스트 통과.
- 4축 독립 총합·미입력 제외·코드 분류 확인.
- 로그인한 계정으로 부산 맥주여행 방(2026-10-24~25)을 생성하고 추천 코스 불러오기 확인.
- 다른 실제 회원에게 초대를 보내는 검증은 수행하지 않았습니다.

전체 백엔드 테스트: 34개 실행, 33개 통과·1개 건너뜀. 브라우저에서 초대 링크 팝업과 방문 시간 저장도 확인했습니다.
