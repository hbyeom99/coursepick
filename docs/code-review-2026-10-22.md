# 2026-10-22 코드 리뷰 및 배포 파일 정리

## 검토 기준

업로드 Coursepick1022 2.zip의 핵심 소스 206개는 로컬과 내용이 일치했다(줄바꿈 제외). 원본 ZIP을 작업 폴더 위에 풀지 않고 구조·내용을 비교했다. 현재 미커밋 변경은 보존했다. DB·권한·회원·실제 코스 데이터를 변경하지 않았다.

## 수정한 문제

| 중요도 | 문제 | 조치 |
|---|---|---|
| 높음 | 자연현상 설명의 부정문도 긍정 근거로 매칭 가능 | 불가·없음·금지 등 부정 문장을 근거에서 제외. 이 규칙은 자연어 의미 검증 전체를 대체하지 않음 |
| 중간 | 사용자 코스 정렬 비교마다 성향 계산 반복 | userCourseRanking에서 코스당 한 번 점수 계산 후 정렬. 기존 순위 규칙 유지 |
| 중간 | 가상 코스 다양성 회피 목록에 Kakao 참조 누락 | 외부 참조 ID도 생성기 ID 형식으로 변환해 중복 회피에 반영. Google 참조도 동일 코스 구성 서명에 포함 |
| 중간 | 검색 규칙 JSON이 웹·API에 중복되어 향후 불일치 위험 | sync_search_rules.py와 일치 검사 제공. backend 루트 독립 배포 지원을 위해 복사본은 유지 |
| 중간 | 홈 진입 즉시 대용량 주소 데이터 다운로드 | 주소가 필요한 화면·상세 진입 시 동적 로딩. 원래 주소는 데이터 로딩 전 유지 |
| 중간 | ZIP에 의존성·빌드·원본 데이터·이전 소스·작업자료 혼재 | 루트 및 backend .vercelignore, 선별 소스 내보내기 도구와 ZIP 생성 |
| 낮음 | 사용되지 않는 태그 분류 상수 | 제거 |

## 배포 산출물

- outputs/coursepick-deploy-source.zip: 351개 소스·이미지·설정 파일과 SHA-256 manifest.
- 원본 비압축 약 750.1MiB → 선별 소스 약 40.8MiB, ZIP 약 26.6MiB. 이는 파일 선별 크기이며 웹 런타임 다운로드 전체 감소율을 의미하지 않는다.
- node_modules, .git, dist, 중첩 이전 coursepick, 원본 여행 데이터셋, work, 비밀 환경파일, DB 백업, 테스트·SQL·문서 자료를 배포 ZIP에서 제외한다.
- 원본 파일은 삭제·이동하지 않았다. 기존 GitHub 자동 배포는 추적 파일과 Vercel 설정을 사용한다. 새 ZIP이 자동 배포에 사용된다는 의미는 아니다.
- ZIP은 소스 패키지다. 웹은 기존 npm 설치/빌드, API는 backend 루트 및 기존 환경변수 설정이 필요하다. 배포나 환경변수 변경을 실행하지 않았다.
- 재생성: python tools/export_deployment.py
- 규칙 검사: python tools/sync_search_rules.py --check
- 규칙 동기화: python tools/sync_search_rules.py

## 검증

- Python unittest: 109개 실행, 108개 통과, 1개 건너뜀(기존 테스트).
- 프론트 회귀 검사: 태그/하위/제목 순위, 점수 1회 계산, 자연현상 부정 근거 배제, 출처 중립 중복 제거, 후보 없는 페르소나 생성 방지 통과.
- Vite 프로덕션 빌드 통과. 일부 큰 번들 경고는 남아 있음.
- ZIP 무결성, manifest, 배포 필수 검색 JSON 포함 및 제외 경로 검사 통과.
- 브라우저는 Work 설정에서 로컬 브라우저 사용이 비활성화되어 화면·콘솔을 확인하지 못했다.
- 실제 외부 API, DB 저장, 로그인·메일·결제·공유 부작용 테스트는 실행하지 않았다.

## 남은 개선점

App.jsx와 누적 style.css의 규모가 크다. 이번에는 대규모 화면 재분리로 동작 위험을 늘리지 않고 검색 순위 로직만 분리했다. 지도 경계·주소 JSON과 한글 폰트가 여전히 크며, 지도 데이터 분할 및 폰트 서브셋은 디자인·지원 문자·지도 기능 검증을 수반하는 별도 작업으로 남는다. 규칙 기반 설명 검사는 오탐을 완전히 제거하지 못하므로 확인된 태그·구조화된 근거가 더 중요하다.
