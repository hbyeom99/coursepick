# 검색 허용 목록과 장소 태그

- 홈·코스 검색·Zip 공동취향 키워드는 homeSearchKeywords.json의 658개 표현만 지원한다. NFKC·공백·영문 대소문자 정규화 외에 임의 조합·오타 보정으로 허용하지 않는다. 장소 추가의 기존 자유 장소명 검색은 별도다.
- 승인된 동의어와 단방향 하위태그 관계는 approvedSearchRelations.json에 둔다. 이 관계가 새 검색어를 허용 목록에 추가하는 것은 아니다.
- 사용자 코스는 정확·승인 동의어 태그 → 승인 하위 태그 → 제목 문자 포함 순, 그룹 내부는 성향 적합도순이다.
- Kakao는 검색어·상호명으로 태그를 만들지 않는다. 원문 분류의 정확한 항목만 허용 표현으로 변환한다. 주관적·편의 조건은 분류 문자열에서 추측하지 않는다. 검색 결과 본문과 자동 태그는 영구 저장하지 않는다.
- 기존 DB 태그는 삭제하지 않고 직접 분류 근거와 기존 태그에 대한 승인 관계로 추가만 한다. 태그만 낙관적 비교 조건으로 수정한다. 기존 태그 변경 충돌은 건너뛴다.
- 맥주 하위: 수제맥주·로컬맥주·IPA·사워에일·양조장·펍·바틀샵. 카페 세부 유형, 체험 세부 활동, 공연 유형도 사용자 승인 목록만 적용한다.
- 감성·힐링·숨은맛집·가성비·주차·예약·동반 가능 여부는 이름·검색어로 추정하지 않는다. 새 의미 관계는 사용자 판단 후 등록한다.
- 백엔드 배포 루트 독립 실행을 위해 backend/home_search_keywords.json 및 approved_search_relations.json에 동일 규칙을 포함한다. test_allowed_place_tags.py가 프론트 원본과의 일치를 검사한다.
