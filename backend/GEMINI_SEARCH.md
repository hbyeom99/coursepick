# Gemini 자연어 검색 설정

자연어 해석은 `POST /api/search/interpret`에서만 실행됩니다. 허용된 검색어는 기존 프런트엔드 규칙으로 먼저 처리하며, 허용어와 일치하지 않는 검색 문장만 Gemini로 보냅니다. Gemini는 검색 조건 JSON만 반환하고 장소 검색·코스 생성·DB 쓰기는 수행하지 않습니다.

## 로컬 키 설정

`backend/.env`에 다음 서버 전용 값을 추가합니다. 키를 프런트엔드 `.env`, `VITE_` 변수, 소스 코드에 넣지 않습니다.

```dotenv
GEMINI_API_KEY=Google_AI_Studio에서_발급한_키
GEMINI_MODEL=gemini-3.1-flash-lite
```

운영 배포에서는 백엔드 서비스의 환경변수에 같은 이름으로 설정합니다. `.env.example`은 변수 이름만 담고 실제 키는 저장소에 넣지 않습니다.

## 적용 제한

- 검색 문장 최대 50자: 프런트엔드 입력과 백엔드 요청 모두에서 검사합니다.
- 로그인 회원은 프로세스당 rolling 24시간 20회, 비회원 세션은 5회.
- 같은 사용자·세션 요청은 5초 간격, 프런트엔드에서 같은 조건의 성공 결과를 탭 메모리에 10분 재사용합니다.
- 응답은 JSON 구조로 제한하고 180 출력 토큰, 6초 제한, 자동 재시도 없음.
- 검색 내용은 서버 로그나 DB에 기록하지 않습니다.

사용량 카운터는 현재 백엔드 프로세스 메모리에 있습니다. 서버 재시작이나 여러 인스턴스 운영 시 전역 합산 한도가 되지 않습니다. 여러 인스턴스를 대상으로 전역 한도가 필요하면 별도 공유 저장소 설계가 필요합니다.
