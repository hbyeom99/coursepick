# 숙소를 연결한 하루 코스

- TourAPI 숙박 콘텐츠(contentTypeId 32)를 기존 관광지·음식점이 있는 지역에서 수집했다.
- 숙소 50개: 서울 33, 경기 1, 인천 2, 광주광역시 7, 용인 4, 천안 3.
- 전주는 기존 관광지·음식점 데이터가 부족해 이번 연결 대상에서 제외했다.
- 좌표·주소·중복·대표 이미지 응답 및 이미지 이용조건을 검토했다. 공공누리 Type1/Type3 대표 이미지만 사용했다. 사진 출처는 한국관광공사 TourAPI이며 Type3 사진은 변경하지 않는다.
- 기존 `places` 440개를 유지하고 `숙소` 카테고리 50개를 추가했다. `rating: 0`은 미평가를 뜻한다.
- `lodging.sql`은 체크인·체크아웃·안내·출처·이미지 이용조건을 저장하는 선택적 `lodging_info` 열을 추가한다. 기존 운영시간에 체크인 시간을 넣지 않는다.

## 앱에서 사용

맞춤 코스 만들기에서 지역과 숙소를 선택한다. 숙소 주변 10km 안의 관광지·식당을 대상으로 기존 규칙 기반 추천을 실행한다. 기존 코스 상세 또는 코스 만들기에서도 첫 장소와 마지막 장소에서 각각 직선 15km 이내의 숙소를 선택할 수 있다.

코스의 `stopIds`는 기존 방문 장소의 고유 ID 목록이다. 숙소는 `accommodationId`로 별도 관리한다. 지도는 숙소 마커 하나와 기존 일정 번호를 표시한다. 이동 경로 계산에만 `[숙소, ...장소, 숙소]`를 사용한다. 다른 중복 장소는 거부한다. 자동차 길찾기는 숙소 출발·복귀 구간을 포함하며, 요청당 경유지 5개를 넘으면 경로를 나누어 합산한다. 도보·대중교통에 자동차 시간을 표시하지 않는다.

상세 화면의 숙소 선택은 `coursepick.accommodations.v1`, 편집 중인 숙소는 기존 임시저장, 완성된 나의 코스는 기존 브라우저 코스 저장에 유지된다. 잘못된 저장 JSON은 초기값으로 복구한다. 기존 공개 코스 레코드는 변경하지 않는다.

현재는 숙소를 기준으로 한 하루 일정이다. 숙박시간은 코스 시간에 포함하지 않는다. 첫날 체크인 전 객실 이용을 가정하지 않는다. 날짜별 1박 2일 자동 일정·예약·요금 확인은 구현하지 않았다. 체크인·체크아웃은 TourAPI 제공값이므로 실제 이용 전에 숙소에 확인한다.
