# 전국 장소 수집

TourAPI의 현재 17개 시·도를 기준으로 관광지·음식점·카페·체험 각각 **최대 300개 신규 장소**를 검토합니다. 기존 장소 ID 및 이름/주소 중복은 제외하고 기존 데이터와 코스는 수정하지 않습니다. 등록량·좌표·이미지 이용조건·설명 부족으로 미달한 수량은 그대로 기록합니다.

체험은 TourAPI 레포츠와 명시적인 체험·공방·농장 등의 장소를 사용합니다. 앱 카테고리는 관광지이며 체험 또는 액티비티 태그로 검색합니다. 보드게임·방탈출 같은 특정 체험이 300개 존재한다는 의미는 아닙니다.

메뉴·장소명·설명·공식 분류를 근거로 기존 앱 태그를 적용하고 중복 태그를 제거합니다. SNS핫플레이스·유명관광지·맛집·포토 등의 태그를 모든 장소에 일괄 부여하지 않습니다. 평점 미제공은 0(미평가), 운영시간 미제공은 빈 값으로 유지합니다.

이미지 URL과 공공누리 Type1/Type3, 장소별 분류 근거는 review.json에 기록합니다. 이미지 픽셀 파일은 다운로드하지 않습니다. 실제 이미지 URL의 지속적인 제공은 원 제공처에 따라 달라질 수 있습니다.

backend 폴더에서 기존 Python 환경으로 실행합니다. 새로운 패키지가 필요하지 않습니다.

```powershell
python nationwide_import.py collect --output <저장폴더>
python nationwide_import.py store --output <동일한 저장폴더>
python nationwide_import.py status --output <동일한 저장폴더>
```

- collection.sqlite3: 요청 결과 캐시, 검토·제외 장소, 지역별 건수. 재실행 시 이어서 수집합니다.
- review.json: 장소 데이터와 태그·이미지 출처/이용조건.
- places.csv: Supabase 필드 이름의 UTF-8 BOM CSV, tags는 PostgreSQL 배열 형식.
- progress.json: 검토 수량, 지역별 수량, 제외 사유, API 원본 유형별 전체 건수.
- places-before.json: 수집 시작 당시 DB 백업(공개 장소 데이터만).
- import-result.json: 신규 저장 수량 및 기존 데이터 보존 검증.

일일 호출 한도(22)에 도달하면 자동 중단하고 상태를 저장합니다. 한도가 초기화되거나 증설된 뒤 같은 collect 명령으로 재개합니다. store는 검토 완료된 장소만 추가하며 반복 실행해도 중복 저장하지 않습니다.

Frontend는 Supabase 결과를 1,000개 단위로 이어서 읽습니다. 검색 및 장소 추가의 지역 선택은 실제 데이터에 있는 지역을 포함합니다. 전국 대량 데이터를 한 번에 지도에 표시하는 것은 별도의 화면 성능 개선이 필요할 수 있습니다.
