# 캠핑 장소 데이터

TourAPI의 캠핑·야영·글램핑 검색 결과 중 기존 여행 지역의 장소 150개를 Supabase places에 추가했다. 좌표, 주소, 중복, 대표 이미지 응답과 공공누리 Type1/Type3 이용조건을 확인했다. 사진 출처는 한국관광공사 TourAPI이며 Type3 이미지는 변경하지 않는다.

기존 앱의 카테고리를 유지하기 위해 관광지 카테고리에 저장하고 캠핑·야외 태그를 부여했다. 이름에 야영 또는 글램핑이 명시된 경우 해당 태그도 저장했다. 자연 태그는 제공 설명에 관련 근거가 있는 경우에만 부여했다. 운영시간 미제공은 빈 문자열, 평점 미제공은 0이다. 숙박·예약 가능 여부는 별도 확인해야 하며 자동으로 숙소로 분류하지 않는다.

검색의 장소 탭과 코스 만들기의 장소 추가에서 캠핑 키워드로 조회할 수 있다. 테마 필터와 마이 관심 키워드에는 캠핑·글램핑을 추가했다. 해당 장소를 포함한 코스에도 태그를 반영한다. 캠핑·야영·글램핑은 취향 점수에서 같은 그룹으로 묶어 한 번만 계산한다.

기존 장소·코스·프로필 레코드는 변경하지 않았다. 다박 일정과 페르소나 코스 재작성은 이번 작업에 포함하지 않는다.
