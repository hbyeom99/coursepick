# 카카오 실시간 장소 검색

- `POST /api/kakao/places/search`: query, region, page(1~45), 선택 latitude/longitude.
- 백엔드 `KAKAO_REST_API_KEY` 사용. 없으면 기존 `KAKAO_MOBILITY_REST_API_KEY`를 사용한다. 같은 앱의 REST 키이며 JavaScript 키를 사용하지 않는다.
- 코스 첫 장소가 있으면 그 좌표에서 20km 반경으로 검색한다. 없으면 국내 사각형 범위에서 지역을 검색어에 반영한다. API 정렬은 정확도순이다.
- 결과와 원문은 DB·파일·캐시·로그에 기록하지 않는다. 응답은 Cache-Control: no-store. 프런트엔드 결과는 컴포넌트 메모리에서만 유지되며 검색어/지역/기준 장소 변경 또는 화면 닫기 시 해제된다.
- 이름과 주소가 정규화 후 일치하고 좌표 차이가 100m 이내인 기존 DB 후보가 하나일 때만 기존 장소 연결 버튼을 제공한다. 모호하거나 주소 표기가 다르면 자동 연결하지 않는다.
- 외부 결과는 직접 코스/최근 장소/저장 장소/대표 이미지 목록에 추가하지 않는다. 기존 DB 장소 연결 후에는 기존 정보만 저장한다.
- 검색 결과 팝업은 기본정보와 카카오맵 링크를 제공한다. 사진·운영시간·리뷰·평점을 임의 생성하지 않는다.
- 이 구현은 기존 DB의 과거 카카오 유래 필드 문제를 해결하는 데이터 정비 작업을 포함하지 않는다.
- 배포는 별도이며 이번에는 로컬 소스만 변경한다.
